# 店舗開発 交通量・駅乗降・周辺人口（スマホ版）

https://knoro-hue.github.io/census-mobile/

地図をタップするか現在地を使うと、その地点の次の情報を表示します。

- 交通量：一番近い道路交通センサス調査区間の12時間・24時間交通量、大型車の割合など（令和3年度 全国道路・街路交通情勢調査、国土交通省）
- 駅の乗降客数：半径1km以内の駅（国土数値情報 S12-25、2024年度）
- 周辺人口：半径1・3・5kmの人口・世帯・年齢構成（令和2年国勢調査 250mメッシュを按分した概算）

計算方法はChrome拡張「店舗開発マップ支援」と同じです。

## データの作り方

国交省・e-Statのサーバーはブラウザから直接読めないため、GitHub Actions（`.github/workflows/build-data.yml`）で取得・変換して `data/` に保存しています。

- `scripts/` を更新すると自動で実行されます。手動では「Actions」→「データ作成」→「Run workflow」。
- 1回の実行は最大約5時間。終わらなかった分は次回の実行で続きから作成します。
- 作成済みのデータを取り直すときは「force」にチェックを入れて実行します。
